# Stock Portfolio Tracker

This is a simple stock portfolio tracker built using Python.

## Features
- Takes stock name and quantity from user
- Calculates total investment value
- Uses predefined stock prices

## Technologies Used
- Python

## How to Run
1. Run stock.py
2. Enter stock name
3. Enter quantity
4. View total investment

## Concepts Used
- Dictionary
- Conditional Statements
- User Input
- Basic Arithmetic
